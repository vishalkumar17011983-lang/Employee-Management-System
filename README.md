# Employee Management System

## 📌 About

This is a menu-driven **Employee Management System** built using **Python** and **MySQL**. It allows users to manage employee records and perform basic database operations through a simple command-line interface.

## ✨ Features

* Show all employees
* Search employee by ID
* Add a new employee
* Update employee salary
* Delete employee
* Generate company analysis report

## 📊 Analysis Report

The project generates:

* Total number of employees
* Highest salary
* Lowest salary
* Average salary
* Department with the highest average salary
* Top 3 highest-paid employees
* Employees with rating greater than 4.5

## 🛠 Technologies Used

* Python 3
* MySQL
* mysql-connector-python

## 🗂 Database

**Database Name:** `company_db`

**Table Name:** `Employee`

Columns:

* Emp_ID
* Name
* Department
* Salary
* Experience
* Rating

## ▶️ How to Run

1. Install MySQL.
2. Install the MySQL Connector:

   ```
   pip install mysql-connector-python
   ```
3. Update the MySQL username and password in the Python file.
4. Run the Python program.
5. Use the menu to perform employee management operations.

## 📸 Features Included

* CRUD Operations (Create, Read, Update, Delete)
* SQL Aggregate Functions
* Parameterized Queries
* Menu-Driven Program
* MySQL Database Connectivity
